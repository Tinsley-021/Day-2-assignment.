About QuickNotes

QuickNotes is a simple tool for capturing my ideas and reminders. It helps keep useful notes organized and easy to revisit.

How to use QuickNotes

  1. Go to the home page.
  2. Type your note in the text area.
  3. Select “Save note” to submit it.

Features

  • A simple note-taking interface
  • Space for ideas and reminders
  • Easy navigation between pages

Keyboard shortcuts

Shortcut Action
Ctrl + S Save the current note
Ctrl + N Start a new note
